Quick Start

Terminal 
# Basic IP lookup

# Look up your own IP
curl -H "X-Api-Key: YOUR_KEY" http://localhost:3000/api/ip/me

# Country only (lightweight)
curl -H "X-Api-Key: YOUR_KEY" http://localhost:3000/api/ip/8.8.8.8/country
